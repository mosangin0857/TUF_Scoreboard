# TUF Scoreboard

TUF 클랜 BJ용 방송 스코어보드 프로그램입니다. SOOP **프릭샷**에 웹(브라우저) 소스로 띄우고, 프로그램에서 누르는 대로 방송 화면이 바로 바뀝니다.

- **종족최강전**: 기존 종최 스코어보드 디자인 그대로 (SET·맵 / 닉네임 / 킬·위치, 종족별 명단·상금)
- **프로리그**: 팀 엔트리, 세트별 맵·종족, 승패 자동 집계
- 인터넷 서버 없이 내 PC 안에서만 동작 (프로그램이 켜져 있는 동안 송출)
- 새 버전이 나오면 자동으로 받아서 알려 줌

## 설치

1. [Releases](https://github.com/mosangin0857/TUF_Scoreboard/releases/latest)에서 `TUF_Scoreboard_Setup_x.y.z.exe`를 받습니다.
2. 더블클릭해서 설치합니다.
   - "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 코드 서명 인증서가 없어서 뜨는 안내이고, 프로그램 문제는 아닙니다.
3. 바탕화면의 **TUF Scoreboard**를 실행합니다.

## 프릭샷 연결 (처음 한 번)

1. 프로그램 **홈 → 프릭샷 연결 · 설정**에서 스코어보드 1, 2 주소를 복사합니다.
   - 기본 주소: `http://127.0.0.1:7777/overlay/1`, `http://127.0.0.1:7777/overlay/2`
2. 프릭샷에서 **소스 추가 → 웹(브라우저) 소스**를 만들고 주소를 붙여넣습니다. 스코어보드 2도 같은 방법으로 추가합니다.
3. 크기는 소스 속성의 **너비·높이**로 조절합니다. 스코어보드가 비율을 유지하며 맞춰집니다.

종족최강전 탭을 열면 종최 스코어보드가, 프로리그 탭을 열면 프로리그 스코어보드가 같은 주소로 송출됩니다.

## 사용 팁

- 창을 닫아도 **트레이(작업표시줄 오른쪽 아래)**에서 계속 송출됩니다. 완전히 끄려면 트레이 아이콘 → 종료.
- 단축키 (조작패널 창이 선택되어 있을 때): `F1` 왼쪽 승, `F2` 오른쪽 승, `Ctrl+Z` 되돌리기
- 미니 탭의 **항상 위 미니 창**을 누르면 게임 화면 위에 작은 컨트롤러만 띄울 수 있습니다.
- 설정에서 **윈도우 시작할 때 자동 실행**을 켜 두면 프릭샷보다 먼저 켜져서 소스 새로고침이 필요 없습니다.
- 맵 목록은 **홈 → 맵 관리**에서 추가·삭제·순서 변경, 약칭(스코어보드 2 표시용) 수정이 됩니다.

## 업데이트

프로그램이 켜질 때와 6시간마다 새 버전을 확인합니다. 새 버전을 다 받으면 상단에 **재시작해서 설치** 버튼이 뜹니다. 누르지 않아도 프로그램을 종료할 때 자동으로 설치됩니다.

## 개발

```bash
npm install
npm start          # 개발 실행 (VS Code 터미널이면 ELECTRON_RUN_AS_NODE 환경변수를 지우고 실행)
npm run dist       # dist/ 에 설치파일 생성 (업로드 안 함)
```

구조

| 경로 | 내용 |
|---|---|
| `electron/main.js` | 앱 창, 트레이, 자동 업데이트 |
| `electron/server.js` | 내장 송출 서버 (127.0.0.1:7777, WebSocket 실시간 전달, 상태 저장) |
| `src/control/` | 조작패널 화면 |
| `src/overlay/` | 프릭샷 웹 소스용 송출 화면 (`/overlay/1`, `/overlay/2`) |
| `src/shared/` | 스코어보드 디자인 (조작패널 미리보기와 송출 화면이 함께 사용) |
| `docs/PLAN.md` | 기획·구조 결정 |
| `docs/RELEASE.md` | 새 버전 배포 방법 |
| `mockups/` | 디자인 목업 |
