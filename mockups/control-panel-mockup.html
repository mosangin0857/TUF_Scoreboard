      안어울리는 BJ좋은 점아쉬운 점
      A · 한 화면형경기 전에 엔트리를 직접 입력하고, 화면이 넓은 BJ모든 정보를 한 번에 보고 바로 고칠 수 있음. 기능을 찾을 필요가 없음버튼이 작아서 방송 중 급하게 누르면 실수할 수 있음
      B · 진행형방송 중 승패만 빠르게 누르고 싶은 BJ큰 버튼, 다음 경기 자동 이동, 실수 거의 없음. 처음 쓰는 사람도 바로 이해엔트리 수정은 다른 화면으로 가야 함
      C · 미니 컨트롤러모니터 한 대로 게임하면서 방송하는 BJ화면을 거의 차지하지 않고 항상 위에 떠 있음혼자서는 세팅을 못 함. A나 B와 같이 써야 함
      추천 조합
      1. A를 기본 화면으로 두고 경기 전 엔트리를 입력
      2. 상단 [진행 모드] 버튼으로 B 전환. 방송 중엔 큰 버튼만 사용
      3. [미니] 버튼으로 C를 띄우는 건 선택 기능. 모니터 한 대 쓰는 BJ용

      셋 다 같은 데이터를 보기 때문에 화면만 바꿔 끼우는 구조라서 추가 작업이 많지 않습니다.
